# 邮箱挖掘渠道（含区域差异）

> 复用自 `market-entry-playbook/references/关键人邮箱挖掘.md`（2026-09-27 实测），
> 按「先锁人再找邮箱」重排。实测基准：50 家分销商中拿到 **24 家具名个人邮箱（48%）**。

---

## 一、先理解为什么「美加难、拉美易」

| 区域 | 现象 | 根因 |
|---|---|---|
| 美国 / 加拿大 | 官网普遍只有表单和电话 | 大公司有正式供应商准入流程，不靠冷邮件获客；隐私合规更严 |
| 拉美（墨西哥/巴西/哥伦比亚）| 大量中小企业老板个人邮箱直接公开 | **有公开登记制度** |

**推论**：
- 给**美加**客户做，预算要留给付费工具或**电话 + 州采购门户**
- 给**拉美**客户做，**先把公开登记库翻干净**，免费常能拿 40%+

## 二、高产渠道（按实测命中率排序）

### ① 巴西联邦登记库 —— 命中率最高

三个镜像直连巴西联邦税务局（Receita Federal）：
- `cnpja.com/office/<CNPJ>` 或 `/en/office/<CNPJ>`
- `casadosdados.com.br/solucao/cnpj/<公司名>-<CNPJ>`
- `portaldatransparencia.gov.br/busca/pessoa-juridica/<CNPJ>`（含招标记录）

**关键技巧**：
1. 🔴 **要跑每个 CNPJ 的所有分支（filial）**。总部邮箱常是 `fiscal@` / `nfe@` / `juridico@`，**分支（如 0002-96）才留老板个人邮箱**。实测 Eletronor 的 `{{CONTACT_EMAIL}}` 就来自分支。
2. **掩码邮箱一律标 D，不要猜**。登记库常显示 `fa****@empresa.com.br`，不可补全。
3. **双源交叉**：`casadosdados` + `portaldatransparencia` 同时确认 = A 级。

**实测战果**：Eletronor（Diretor 本人）、Elecab（Titular 本人）、Elétrica Tensão（Sócio-Administrador 本人）—— 三个老板级邮箱，全部双源确认。

### ② 美国州政府采购门户 —— 被严重低估

URL 模式：
```
njstart.gov/bso/external/vendor/vendorProfileOrgInfo.sda?external=true&vendorId=V00XXXXXX
```
档案页直接公开 **Vendor Email + Emergency Contact Name + Emergency Email**，**往往是具名个人邮箱**。

同类门户（换州即可复用）：
- 宾州 PA eMarketplace
- 纽约 NY OGS
- 马萨诸塞 MA COMMBUYS
- 得州 TX SmartBuy

**实测战果**：`{{CONTACT_EMAIL}}`（{{COMPANY}}）、`{{CONTACT_EMAIL}}`（{{COMPANY}}）—— 都是**在州政府供应商档案里亲眼看到的**。

### ③ 墨西哥 DirInd 分州目录

```
dirind.com/die/<城市>-<州码>-distribuidores1.html
例如 dirind.com/die/puebla-pue-distribuidores1.html
```
**中小分销商老板的个人邮箱富矿**。

**实测战果**：一页拿到 12 个具名邮箱，覆盖 9 家公司。

### ④ 官网 Locations / Branches 页 —— 比 Contact 页含金量高

**Contact 页通常只有表单，但 Locations / Branches / 门店页常逐个列出分店负责人的姓名和邮箱。**

**实测战果**：Lumen（{{COMPANY_DOMAIN}}/en/locations）一次公开 9 个具名员工邮箱，并据此确认全公司格式为 `{名}.{姓}@{{COMPANY_DOMAIN}}`（重音转写，é→e），可安全推断总裁邮箱。

### ⑤ 信用申请 / 供应商注册页 + PDF

搜索关键词：`credit application` / `vendor application` / `supplier registration` / `crédito` / `alta de proveedores` / `cadastro de fornecedores`

这类页面常直接给出采购流程入口邮箱。**比 `info@` 有价值得多**——它能把你带进开户流程。

**实测战果**：`{{CONTACT_EMAIL}}`、`{{CONTACT_EMAIL}}`、`{{CONTACT_EMAIL}}`、`{{CONTACT_EMAIL}}`、`{{CONTACT_EMAIL}}`

**技术提示**：PDF 信用申请表下载后用 `zlib` 解压流再正则匹配，比在线预览更可靠。

### ⑥ 官网团队页

拉美公司常用 `/nuestro-equipo` / `/quem-somos` / `/nosotros`。
哥伦比亚 Dielco 把 10+ 员工的姓名+职务+邮箱全部公开。

### ⑦ 加拿大专用渠道

| 注册/协会 | 渠道 | 拿什么 |
|---|---|---|
| 联邦注册 | `opengovca.com/corporation/<ID>`（用 WebFetch，curl 易被拦）| 注册号、成立史、董事、改名史 |
| 安省 | Ontario Business Registry（需登录，不可用则如实标注）| 注册号、董事 |
| BC | BC Registries（登录墙，标注未取）| 同上 |
| 行业执照 | ESA（安省承包商执照号）/ Technical Safety BC | 执照有效性 |
| 协会名录 | MineConnect / ECABC / AIEC / MPUA / NAAUD / EFC | **会员页常直接列姓名+头衔+邮箱** |

⚠️ 查无联邦记录 ≠ 非法（很多公司仅省注册）；必看**改名史**与**解散-复活**（信控风险）。

### ⑧ 其他次要渠道

- 品牌方经销商名录（ABB / Schneider / Legrand / WEG / Siemens 拉美经销商页）
- 联邦承运登记 / 城市开放数据（BrokerSnapshot、opengovca.com）
- 行业媒体（tED magazine、Electrical Wholesaling、MDM、revistaei.cl）
- 展会参展商名录
- **LinkedIn 公开帖** —— 有人在帖子里自己署名公示邮箱（实测拿到 `{{CONTACT_EMAIL}}`）

## 三、邮箱证据分级（必须严格遵守）

| 等级 | 定义 | 可否直接发 |
|---|---|---|
| **A-个人** | 公开页面上**亲眼看到**，且含真人姓名 | ✅ 可直接发 |
| **A-部门** | 亲眼看到，但是职能邮箱（`credit@` / `applications@`）| ✅ 可直接发，价值高于 `info@` |
| **B-推断** | 同域名已确认存在具名邮箱，据此推断格式。**必须写明依据** | ⚠️ 必须先验证 |
| **C-通用** | 只有 `info@` / `sales@` / `ventas@` / `contato@` | ❌ 不要群发，仅点名转交 |
| **D-未找到** | 确实没找到 | ❌ 走电话 / LinkedIn / 表单 |

**铁律**：
1. 🔴 **绝不编造邮箱。** 没找到就写「未找到」。
2. **B 级推断必须有依据**——同域名下至少一个真实存在的具名邮箱。无依据的猜测一律标 D。
3. **第三方数据商（RocketReach / Apollo / LeadIQ / Wiza / ContactOut / prospeo / Lusha）的邮箱格式只能作线索**，标「第三方宣称，未证实」，**不算 A 级**。
4. **掩码邮箱不补全。**

## 四、推演邮箱的可执行阶梯

逐个实测（**不批量盲发**），配合对照测试（先测已知真实的 `info@` 排除工具假阴性）：

```
{first}@ → {first}.{last}@ → {last}@ → {fi}{last}@ → {fi}{li}@
```

**置信度评分**：政府/官网明文 +2；第二独立源 +2；样本印证 +1；B2B 单源 +1；纯推演 0；catch-all −2。

- **≥4 分才可作主送**
- **≤2 分只能备选 + 电话验证**

**停止规则**：
1. 拿到具名决策人直邮（≥4 分）→ 可停 L3–L5（L1 已查）
2. 仅有角色邮箱 → **L-1 至 L6 全走完 + 必跑升级三步**
3. 交接单必须附**覆盖清单表**（L-1、L0–L7 每行 ✅/⚠️/❌）

## 五、邮箱验证（发信前）

B 级必须验证；A 级也建议验证（公开页面信息可能过期，比如人已离职）。

工具：Hunter.io 免费额度（25 次/月）、NeverBounce 试用、ZeroBounce（约 $0.004/条）。

**注意**：Gmail / M365 的 SMTP RCPT 探测会返回假 250，**L3 SMTP 验证不可靠**，只作参考。

## 六、人员与股权信息必须复核

**实测发现 8 处过期信息**（一份 2 个月前的调研）：CEO 已退休 8 年、公司已被收购、CNPJ 已注销、人名张冠李戴。

**建议：名单每 6 个月复核一次**，重点核对「关键人是否还在职」与「公司是否被收购」。

> 这正是 `still_here` 四栏存在的理由。**不核就发 = 发给已离职的人。**
