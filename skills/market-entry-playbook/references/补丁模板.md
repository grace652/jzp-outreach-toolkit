# 流水线补丁模板

## 一、为什么必须打补丁

`jiezou-kb` 的打分模型是按「美加主攻」设计的。**任何新市场的线索导入后都会被自己的模型筛掉。**

实测证据（2026-09-27，76 家南美机构名单）：

```
候选 76 条：A 0 / B 0 / C 2 / D 74
```

拉美最大电力公司 Eletrobras（AXIA Energia）得 **0 分**，判为 **D 级「暂不跟进」**。

## 二、根因（两处，缺一不可）

### 根因 1 · `COUNTRY2` 缺新市场国家

`scripts/customs_normalize.py:149` 的 `COUNTRY2`（英文国名 → 2 位码）只覆盖了部分国家。

- **英文来源**（ImportYeti / Trademo / 英文名录）→ `country2_of()` 返回 `""` → 走兜底分支
  ```python
  add(3, WEIGHTS[3][0], "国别未识别，按非目标市场处理")   # −15
  tags.add("国别未知")
  ```
- **中文来源**（广交会名录等）→ `CJK_COUNTRY` 能解析出码 → 但走
  ```python
  add(3, WEIGHTS[3][0], f"非目标市场（{c2}）")            # −15
  tags.add("非目标市场")
  ```

**两条路径都扣 15 分**，只是标签不同。

### 根因 2 · 市场分层集合未覆盖

`SECONDARY_MARKETS` 只有加勒比与中美洲，新市场一个都没有。

## 三、补丁写法

### 补丁 A · 识别（自测基线不受影响）

**文件**：`scripts/customs_normalize.py`（2 处）

**改动 1** —— `COUNTRY2` 追加新市场英文全名：

```python
    # 新市场（YYYY-MM 新增）。只加全名，不加 2 位码——见下方说明。
    "BRAZIL": "BR", "CHILE": "CL", "PERU": "PE", "COLOMBIA": "CO",
    "ARGENTINA": "AR", "BOLIVIA": "BO", "PARAGUAY": "PY", "URUGUAY": "UY",
    "VENEZUELA": "VE", "GUYANA": "GY", "SURINAME": "SR",
```

**改动 2** —— `SECONDARY_MARKETS` 纳入新市场：

```python
SECONDARY_MARKETS = {
    "MX", "PR", "DO", "TT", "JM", "BS", "BB", "BZ", "GT", "HN", "PA", "CR",
    # 新市场（YYYY-MM 新增）。此前这些国家既不在 TARGET 也不在 SECONDARY，
    # 会被判为「非目标市场」扣 15 分并打标签，与新战略冲突。
    # 第一梯队（产品可直接适配）：
    "BR", "PE", "CO", "EC",
    # 第二轮（需重设计）：
    "CL", "AR", "BO", "PY", "UY", "VE",
}
```

### 补丁 B · 分层标签（自测基线不受影响）

**改动 3** —— 新增分层集合（接在 `SECONDARY_MARKETS` 之后）：

```python
# 分层标签用（不参与打分，仅用于线索表打标与筛选）。
LATAM_60HZ_MARKETS = {"MX", "BR", "PE", "CO", "EC"}
LATAM_50HZ_MARKETS = {"CL", "AR", "BO", "PY", "UY", "VE"}
```

**改动 4** —— `scripts/lead_scoring.py` 打分分支加标签：

```python
    elif c2 in cn.SECONDARY_MARKETS:
        add(2, WEIGHTS[2][0], f"次级美洲市场（{c2}）")
        # 分层标签（不影响分数，只用于线索表筛选与话术分组）
        if c2 in cn.LATAM_60HZ_MARKETS:
            tags.add("南美60Hz优先")
        elif c2 in cn.LATAM_50HZ_MARKETS:
            tags.add("南美50Hz第二轮")
```

### 补丁 C · 真正调权重（**慎用**）

会改变 `data/fixtures/expected_scores.csv` 基线，`selftest_pipeline.py` 会报出哪一条不一致，需要按 README 说明重新生成基线。

**这是会动到审计链的改动。建议先用标签跑一个季度，确有需要再考虑。**

## 四、⚠️ 绝对不要做的事

**不要给 `COUNTRY_ALIASES` 加 2 字母码。**

`country2_of()` 匹配的是 `buyer_country + buyer_address + buyer_region` 三段**自由文本**，用宽松正则：

```python
if re.search(rf"(?<![A-Z]){re.escape(name)}(?![A-Z])", blob):
```

后果：地址里的 `"ABC ELECTRIC CO., LTD"` 会命中 `CO` → 判定为**哥伦比亚**。`PE` / `AR` / `BR` / `CL` / `BO` 同样有误伤风险。

（现有表里的 `CA` 已经承担了这个风险，那是历史遗留——**不要因为「已有先例」就扩大风险面**。）

**如果来源只给 2 位码**，正确做法是在 `local_csv` 适配器里用 `--map` 把该列映射为 `buyer_country2`（`lead_scoring.py:120` 会优先读这个字段，跳过文本推断）。

**另外**：`REGION_NAMES` / `REGION_LABEL` 只覆盖美国州名与加拿大省名。若要补新市场行政区划，注意**巴西州码与美国的撞车**：PA / MA / MT / MS / AL / SC / PR。`region_of()` 对 2 字母 token 是无条件匹配的。**建议新市场地区只存全称，不存州码。**

## 七、必须向用户说清楚的一件事

**打完补丁后分数可能仍然很低。**

目录型名单的数据完整度通常只有 ~20%（没有票数/金额/日期/供应商），而打分模型里权重最高的信号正是这些（「竞对买家」+30、「采购频次高」+15、「近期活跃」+12）。

> **低完整度的 35 分不能和提单口径的 170 分直接比较。**（`jiezou-kb` README 原话）

所以：
1. 定向名单的用途是**人工外呼**，不是打分排序
2. 想要打分有意义，必须补**提单级数据**（美国用 ImportYeti 免费版；南美用 Trademo / Volza 试用版）
3. **两条线并行**：定向名单走人工触达，提单数据走流水线打分
