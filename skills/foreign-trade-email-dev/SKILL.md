# 外贸邮件开发客户

## 一、这个 skill 做什么

用**邮件**把陌生外贸客户从首次触达一路推进到下单前。产出物永远是**可直接发送的英文邮件正文** + 中文批注。

方法论来源：毅冰《外贸高手客户成交技巧》1/2、《十天搞定外贸函电》、《万能开发信模板100篇》、《39篇外贸邮件模版》、《毅冰9封曾拿下客户的开发信》、《展会75封展会跟进模板》等。

2. 处在**开发 → 成交前**的阶段吗？
3. 触达渠道是 **email** 吗？

## 三、工作流

### Step 1 · 定位客户所处阶段

```
客户从哪来？          名录/搜索 → 冷触达       展会名片 → 展后跟进
                     转介绍   → 可提引荐人     领英     → 【外延】转 out-of-scope/领英与社媒.md
                     老客户   → 二次开发

有没有回应？
  从未回应 → Mail Group 序列（03）
  未看邮件 → 04「未看邮件催看」
  已读未回 → 04「已读未回」
  有回应   → 询盘回复 → 报价 → 议价（05）
  到了样品 → 06
  样品后拖 → 06「推进成交」
  长期沉默 → 07「二次开发」+ 注意下方「能力缺口」
```

### Step 2 · 取骨架

从对应参考文件里取最贴近**本次品类 / 客户来源 / 客户国别**的骨架，**不要每次从零写**。

### Step 2.5（可选）· 取新信息点

**只在「带新信息」类邮件触发**：跟进信、破冰、Mail Group、长期培育。
**不在**询盘、报价、议价、样品类触发 —— 那些场景塞行业新闻会稀释焦点。

有匹配的行业数据时跑一次（详见 `references/09-行业信息融入.md` §四）：

```
PY=python3
cd "<项目根>/行业数据"
$PY 抓取/抓取行业数据.py --pick --geo <US|CA> --buyer <EPC|utility|distributor> --product <distribution|power> --limit 3
```

取到 1 条 → 按 `09` §五 写成开场句；**取不到 → 按 `09` §八 回退，不要编造**。

### Step 3 · 填参数（强制）

素材里的具体专名一律替换，**不得照搬**：

```
人名 → [Name]     公司 → [Company]    产品 → [Product]
国家 → [Country]  金额 → [Amount]     日期 → [Date]
```

**禁止编造**：认证、年限、客户名、订单数字。我方公司信息（`company-profile` 或用户当次提供）里没有的，一律不写，宁可留 `（待填）` 并提示用户。

### Step 4 · 输出格式

```
【Subject 备选】
1. ...
2. ...
3. ...

【正文】（英文，可直接发）
<email body>

【中文批注】
- 骨架：<取自哪个文件 / 哪种体裁>
- 为什么这么写：<一句话>
- 待确认：[缺失或我代拟的信息]
```

### Step 5 · 自检（全过才输出）

- [ ] 所有 `[ ]` 占位符已替换，或已标注「待填」并提示用户
- [ ] 无编造的认证 / 数字 / 客户名
- [ ] 首封 ≤150 词；跟进信 ≤120 词
- [ ] Subject 3–6 词，无全大写、无感叹号堆叠
- [ ] 无 spam 触发词（free!!!、guarantee、100%、act now、全大写标题）
- [ ] 附件 ≤3M，单封 ≤5 个，不用 RAR/ZIP
- [ ] 英文标点后有空格的半角格式；无中文标点（，。！）、无书名号《》
- [ ] 语气：专业、克制、给客户台阶，不谄媚不压迫
- [ ] 一次只给一个主推版本（用户要变体时再给第二个）

## 四、核心纪律（毅冰方法论）

1. **买家思维**：客户最先判断的是「这家供应商靠不靠谱」，不是「你的价格低不低」。信里至少回应「信任」一项。
2. **价值输出而非疑问**：给明确方案和钩子，别抛一堆问题让客户做功课。
3. **禁止编造**：宁缺毋滥。没有的资质不写。
4. **一次只给一个主推版本**。
5. **别急着说 Sorry**：欧美语境下 `Sorry` 近似承担责任。非己方过错不要道歉。
6. **邮件要短**：开发信 3C 原则（Clear / Concise / Correct），首封 60–150 词。作者原话：「开发信的精髓就是简洁、简洁、再简洁。」

## 五、能力缺口（遇到时如实告知，不要硬编）

素材里**确实没有**的三块，遇到对应场景要明说「毅冰素材里没有这个方法」，而不是编：

1. **长期失联客户重新激活** —— 三本方法论书 + 函电全部 0 命中。只有「一周内未回」的短期跟进，没有半年以上的 cold re-touch。
2. **正向逼单 / 促单邮件** —— 只有反面案例（《成交技巧2》案例1-4「让人崩溃的催促」、案例1-3「难以容忍拖延」），讲「别怎么催」，**没有「该怎么促」**。
3. **独家代理 / 区域保护** —— 仅提及，无专章。

> ℹ️ **另有「外部行业信息融入」已补齐** —— 毅冰有专章（《万能开发信模板100篇》§1.5「市场信息动态分享型」），
> 执行细节（筛选 / 取数 / 写法 / 回退）见 `references/09-行业信息融入.md`，
> 并已接入项目本地的行业数据模块。

## 六、素材库不在本机时怎么办

> ⚠️ **素材库不随本 skill 分发。** 新机器上按以下四步执行，**不要报错、不要中断任务**：

**第 1 步 · 先判断**
本次任务是否落在核心范围（判定三问全「是」）？
→ 是：**直接做，不读素材清单、不索取任何文件。** `references/01`–`08` 已自足。

**第 2 步 · 需要时才查清单**
**只有两种情况**才读 `references/00-素材清单.md`：
- ① 任务命中 `out-of-scope/` 八类之一
- ② 需要填我方公司信息而用户未提供 → 用 `references/company-profile.template.md`（**在 skill 内，无需索取**）

**第 3 步 · 精确索取**
按清单的「索引 A · 需求映射表」定位当前任务，**只索取那一行列出的文件**，并说明用途与体积：

> 「完成这个任务需要 `外贸高手客户成交技巧2-OCR全文.md`（446KB，含 60+ 编号案例）。你有的话给我路径，我直接读。」

用户若把素材包解压在某处，请其告知**挂载点路径**，后续按 `<挂载点>/<相对路径>` 读取。

**第 4 步 · 拿不到就降级**
用 `references/` 现有骨架完成任务，并在回复中写明：

> 「完整素材库不可用，本次基于骨架完成，`<缺失项>` 未覆盖。」

**不编造。** 单份文件缺失只降级该份，不要整包判空。

### 其他约束

- **`广交会采购商名录.csv`（129MB / 805,139 行）永远不要读** —— 查询走 `scripts/query_cantonfair.py`
- 素材是 OCR / PDF 抽取文本，存在形近字误差（来→米、梯→样）。**引用金额、日期、认证编号前需核对原图。**
