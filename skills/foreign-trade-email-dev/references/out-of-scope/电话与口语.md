## 一、核心差异

口语和书面邮件的最大区别：**口语可以啰嗦、可以寒暄、可以重述确认**；邮件必须短。

但有一条通用纪律（毅冰）：**谈判时千万不能操之过急，要步步为营，即便退让也要有条件地「战略撤退」。**

---

## 二、常见场景的口语表达

### 汇率 / 涨价（客户砍价时解释原因）
三大理由：人民币升值、人工成本上涨、原材料涨价。

**关键介词**：`against` 表示「兑换」，**绝对不要用 to 或 compare**。
```
The exchange rate of RMB against USD...
```

**「人民币升值很快」不要用 increase**（英语中形容货币升值有专门说法，用 increase 会显得不专业）。

### 货币比较
```
What's the exchange rate of [Currency A] against [Currency B]?
```

### 取消订单
（见《毅冰私房英语书》本章小结：取消订单、原料涨价、汇率问题、测试问题、交期推迟、验货没过 —— 都是高频突发状况）

### 交期推迟
```
We have to postpone the shipment to [Date].
```

### 测试 / 验货问题
```
The goods failed the [test name] test.
```

## 三、电话沟通的 Recap 习惯

**打完电话必须发一封 recap 邮件确认要点。** 这是毅冰强调的动作，也是口语与邮件的衔接点：

```
As per our discussion on the phone, you confirmed [X] points as follows:
Firstly, you accept our new price, [Amount]/pc.
Secondly, ...
Thirdly, ...
Please correct me if I misunderstood anything.
```
