## 为什么要隔离

这 8 类与「邮件开发客户」相邻，但**不属于本 skill 的核心范围**（判定三问至少一条为「否」）。放在同一目录但默认关闭，是为了：

- 避免 SKILL.md 过长导致误触发（用户问「展会怎么接待客户」不该激活邮件 skill）
- 需要时又能一键取到，不用另建 skill

## 使用方式

1. 用户明确提到上表左列的场景 → 读取对应文件
2. 该文件给出：**核心要点 + 关键句式/模板 + 完整素材出处**
3. 若该文件内容不足以完成任务，去文件里标注的原始素材路径取完整版
4. **在回复里说明这是外延能力**，让用户知道已超出邮件开发的核心范围

## 素材路径

本目录各文件末尾的「素材出处」是**素材库位置，不随本 skill 分发**。

- **需要精确知道要带哪几份文件** → 读 `../00-素材清单.md`（有按任务分类的需求映射表）
- **本机没有素材库** → 不要报错，按 SKILL.md 第六节的四步降级流程处理
- **本目录的说明通常已够用** —— 多数外延场景不需要原始素材
