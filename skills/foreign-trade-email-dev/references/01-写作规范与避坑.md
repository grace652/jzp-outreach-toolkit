# 01 · 写作规范与避坑

> 来源：毅冰《45个外贸经典话术分享》2.5–2.9 / 3.4–3.9 / 4.1–4.6；《万能开发信模板100篇》1.1

---

## 一、主题（Subject）写法

### 1.0 版（搜索来的客户，直接）
`Opportunity` / `Sales & Marketing` / `One Channel`
→ 缺点：太泛，像群发。

### 2.0 版（四种取向，选一）
1. **直接型**（Direct）
2. **聚焦产品**（Focusing on the product）
3. **显示优势与差异**（Showing advantage and differentiation）
4. **吸引潜在客户**（Attracting potential customer）

### 3.0 版（最推荐）
- **换主题**：序列里每封都换，避免客户批量删同一串
- **带具体信息**：`[Product] with moderate price & high quality`、`[Product] with [Certificate] approval`、`Fast delivery time with guarantee`
- **`Re:` 开头**：伪装成回信，回复率更高。例：`Re: [Company] / [Product] vendor`
- 长度 **3–6 词**，无全大写、无感叹号

### 铁律
- **不要用全大写**（中东客户除外 —— 他们偏好大写+简单英文）
- **不要出现 `Free!!!` `100%` `Guarantee`** 等垃圾邮件触发词
- 标题里放**对方关心的价值点**，不是放自己的公司名

## 二、正文格式规范

| 项 | 规范 |
|---|---|
| 版式 | 平头式（Block format），段落间空一行 |
| 字体 | Arial / Calibri / Helvetica 等标准商务字体；**不要用宋体** |
| 字号 | 统一，不要混排 |
| 颜色 | 单色。**不要一封邮件多种颜色** |
| 标点 | **英文半角**，标点后紧跟一个空格 |
| 书名号 | 英文里**没有《》**，改用双引号 `""` |
| 感叹号 | 少用，不要连用 |
| 日期 | 全称，如 `July 8th, 2012` |
| 首封 | **不要插图片或附件**，容易被拦截 |
| 人称 | 用 `We` 不用 `I`（代表公司） |
| 邮箱 | 用**企业邮箱**，不用免费邮箱 |

## 三、语气分级（同一件事，五种力度）

按需要的强硬程度选，**从轻到重**：

```
Can you send me the PI today?
Could you send me the PI today?
Could you please send me the PI today?
Could you please help to send me the PI today?
Sorry to push you again. Could you please help to send me the PI today?
```

**慎用表达**（容易被理解成指责）：
- `Regarding this point, my understanding is...` → 潜台词是「你说的都是错的」
- `It is one of our company rules.` → 生硬，改成 `Please help to support us.`
- `We have to charge you the sampling cost.` → 改成 `Could you please share / pay the sampling cost with us?`
- `We couldn't ship the goods before Jun. 15th.` → 改成 `I'm really sorry that we couldn't ship...`

## 四、附件规范

| 项 | 标准 |
|---|---|
| 单封邮件总大小 | **≤3M**，最好 <1M |
| 单封附件个数 | **≤5 个** |
| 压缩包 | **禁止** RAR / ZIP |
| 图片 | 用 Photoshop 压缩，**标注尺寸**，合并成一个 PDF |
| 命名 | 必须重命名，如 `shipping mark & side mark.pdf`，**不要 `IMG1068.JPG`** |
| 格式 | jpg / pdf / doc / xls / ppt 均可 |
| 超量怎么办 | **拆成多封不同主题的邮件发**，不要硬塞一封 |

## 五、反垃圾邮件（别让你的开发信进垃圾箱）

四个主要触发点：
1. **敏感词**：`free`、`100%`、`guarantee`、`cheapest`、`act now`、`click here`
2. **IP 问题**：用免费邮箱 / 代理 IP 群发
3. **邮件正文里的链接**：首封尽量不放外链
4. **附件过多或过大**

其他：
- **乱码**：默认字体是「宋体」会导致乱码，改用 Arial
- **不针对性**：没人喜欢群发邮件。**一封邮件对一个人**（One email for one person）

## 六、10 大常见错误

1. 太长、句子太多，第一眼抓不到核心信息
2. `From the internet...` 开头 —— 一眼就是冷推销，不够好
3. 花大段介绍自己公司 —— 客户没兴趣
4. 大段可删的句子，没有实质内容
5. 结尾是最烂的一句（如 `please visit our website`）
6. 满篇客套寒暄、问天气
7. 抛一堆问题让客户做功课
8. 附件过大 / 用压缩包 / 图片没处理
9. 全大写标题 / 感叹号连用 / 多色字体
10. 群发（标题内容都一样）

## 七、CC / BCC 策略

- **CC**（carbon copy，抄送）：让相关方知情，如抄送自己的主管
- **BCC**（blind carbon copy，密送）：群发时隐藏收件人
- **注意**：开发信群发用 BCC 时，**客户看得出**。真正有效的做法是**一封邮件对一个人**，标题和内容都不同

---

## 八、CC 与收件人栏的细节

- 收件人栏的**先后顺序**也有讲究（正式场合按职级/重要性排）
- 想让客户容易联系到你：签名里给全 姓名 / 职位 / 邮箱 / 电话
- 客户把你的邮件转发给同事时，对方也能轻易找到你

---

## 九、邮件长短：长还是短？

**看阶段**：
- **首封开发信**：短，60–150 词。3C 原则（Clear / Concise / Correct）
- **Mail Group 第 1 封**：可以稍长（自我介绍 + 来源）
- **第 2 封起**：每封短、单一主题
- **报价类**：可以长，但要有表格结构，不能是文字堆

作者金句：「把最核心的卖点放在最前面，让对方觉得你是行家。」

- [ ] Subject 3–6 词，无全大写、无感叹号、无 spam 词
- [ ] 用企业邮箱，人称用 We
- [ ] 英文半角标点，标点后有空格的空格
- [ ] 无中文标点（，。！）、无书名号《》
- [ ] 字体为 Arial/Calibri，单色，字号统一
- [ ] 附件 ≤3M、≤5 个、无 RAR/ZIP、已重命名
- [ ] 首封无附件无图片
- [ ] 一封邮件对一个客户，标题内容都个性化
- [ ] 结尾不是 `please visit our website` 这类懒结尾
