# JZP 公司自有资料 · 总入口

## 零、这个 skill 解决什么

对外发信 / 回客户 / 写方案时，凡是涉及**我们自己的资质、参数、条款**，
**不能凭记忆或推断回答** —— 说错证书号、把产能说成认证范围、误称 CSA，
每一条都是**对客户的事故**。

本 skill 指向公司自有资料的**唯一权威位置**，并把**最容易说错的口径**固化成规则。

## 一之二、🔴 发送包体积红线（2026-10-02 实测事故）

给客户备资料包时**整包极易超限**：

| 资产 | 体积 |
|---|---|
| UL 证书（2 本 CoC） | **2 MB** ✅ |
| 样机试验报告（3 份） | 2 MB |
| 质保函 | 1 MB |
| 规格书 Catalog | **16 MB** ⚠️ |
| Reference List | **18 MB** ⚠️ |
| **整套** | **37 MB** ⚠️ 超 Gmail 25 MB 上限 |

**实测事故**：一次回复信附了「2 本证书 + 整包 zip（18MB）+ Catalog（31.8MB）」= **49.5 MB**，
**超多数企业邮件网关 25–30 MB 上限**。

**规则**：
- **推荐组合 = 证书 + 试验报告（约 4 MB）**。
- **单文件 >10 MB 一律走云盘链接**（Catalog、Reference List 都是）。
- ⚠️ **发到 `Sent Messages` ≠ 对方收到** —— SMTP 中继接受 ≠ 收件方接受。
  发完**盯 24 小时内退信**。
- 资料包的既定结构见 `~/Desktop/Zac-ZeusElectric-Package/`（`1_Datasheets` / `2_UL-Certificates` /
  `3_Sample-Test-Reports` / `4_Warranty-Support` + 单独 draft txt）—— **照这个做，不要自创格式**。

**项目内镜像**（写信时优先用，因为路径短）：

## 二、🔴 认证口径（最容易说错，违反即事故）

**权威文档**：`jzp-americas-dev/开发信项目/02_product_positioning.md` §四（按原件 PDF 逐字核对）
**速查**：`开发信项目/资料库/证书/README.md`

| 证书 | 美国 | **加拿大** | 标准 |
|---|---|---|---|
| **E541626** 电力变 `XQNU` | HV 72–121 kV，**750–110,000 kVA** | **UL-CA-2425819-0（依 CSA C88）** | IEEE C57.12.00 |
| **E541627** 配电变 `XPLH`（三相美变/ZGS） | **45–5,000 kVA** | **CUL 75–3,000 kVA**（CSA C227.4） | IEEE C57.12.00 + C57.12.28 |

- 美国 CoC：`UL-US-2433357-0`（2024-09-03）｜`UL-US-2444286-0`（2024-11-11）
- **持证人**：`JZPE POWER TRANSFORMER (JIANGSU) CO., LTD.`（泰州姜堰）
- **署名主体**：`JZPE POWER TRANSFORMER CO., LTD.`（苏州外贸点）→ **两者不同，见红线 3**

### 三条红线

1. **UL 只覆盖液浸类** —— **干式变没有 UL**。对美客户**不要推干变**（NEC 要求 listed，提了等于自曝）。
2. **UL 区间 ≠ 公司产能** —— UL 号管 750–110,000 / 45–5,000 kVA；
   公司自述 **500 kV / 480 MVA 是产能，不是 UL 范围**。**不可把 500 kV 挂在 UL 名下。**
3. **持证人 ≠ 署名主体** —— 客户追问主体差异 → **不自行解释，转人工**。

### 绝不能说

| ❌ | ✅ |
|---|---|
| `CSA Certified` | `built to CSA/IEEE standards`；或陈述事实「加拿大证书依 CSA C88 / 覆盖 75–3,000 kVA」 |
| `SASO` / `SONCAP Certified` | 未持有，不提 |
| 干式变有 UL | 对美客户不谈干变 |
| 单相柱上变 / 变电站小主变「已认证」 | 二者**只有 ECD Letter（项目计划函）** → 只能说 `the project is underway` |

> ⚠️ **ECD Letter ≠ 证书。绝不出示 ECD Letter 充作证书。**
> ⚠️ **CSA Group Special Inspection ≠ CSA 产品认证** —— 那是**逐单标签检验**，
> 可以谈「per-order special inspection」，**不能说「CSA certified」。**

### 📌 对外出示证书前（必做）

1. **先与 Tong Shen（`{{SENDER_EMAIL}}`）确认版本** —— 以**最新版**为准。
2. 客户会在 **UL Product iQ** 核验编号 —— **查不到比不写更糟**。
   不确定时改成不带编号的 `UL certified, tested to IEEE C57.12 and ANSI standards`。
3. **证书区间漏掉加拿大那一半是常见错误** —— 加/美客户都要给全（见上表）。

## 四、产品切片（按客户电压等级切，切错 = 显得不懂市场）

| 客户类型 | 只谈 | 刻意不提 |
