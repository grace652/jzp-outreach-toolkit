# P2 · 模板全文提示词（Notebook ① 模板库用）

适用素材：39篇外贸邮件模版、45个外贸经典话术、毅冰独家邮件群组2023、万能开发信模板100篇（解密副本）、毅冰9封曾拿下客户的开发信（解密副本）、展会75封跟进模板、展会邮件模版、130条常用金句、电话口语57句、领英加客户好友 docx。

**这类素材是 agent 的弹药库，原则：全文保真，禁止摘要改写。**

## 使用步骤

1. 一本书 = 一个 source。粘贴提示词正文并替换 `{书名}`
2. **必须分批**：模板多的书（100篇/39篇/75封）每批 10 篇，看完输出后回复「继续下一批」
3. 产出粘贴到 `kb/staging/模板-{书名}.md`（多批合并到一个文件）
4. 交叉验证：问「全书共 N 篇，我已转录 M 篇，列出遗漏的篇目序号和标题」
5. 移入 `kb/02-templates/`，重跑 `scripts/build_index.py`

## 提示词正文（从这里开始整体复制）

```
你在为一位 AI 外贸顾问整理模板库。请把《{书名}》中的模板逐篇全文转录成 markdown，严格遵守：

1. 【最高优先级】逐字保留原文正文，禁止摘要、改写、缩写、意译。英文邮件保持英文原样。这是给 AI 复用的弹药库，漏一句就少一种打法。
2. 卖家推广页（含"hxg3366"、微信二维码、课程广告的页面）整页跳过，不计入篇数。
3. 专名参数化（仅替换具体人名/公司名/产品名，不改动句式）：
   人名→[Name]，公司→[Company]，产品→[Product]，国家→[Country]，金额→[Amount]
   作者署名（Yibing/毅冰）→[Yibing]
4. 每篇格式：
### {序号}. {场景中文名}
- 适用场景：一句话（什么情况下用这封/这句话）
- Subject:（邮件类保留；话术类省略此行）

> 邮件/话术全文（引用块包住）

5. 开头加 frontmatter：
---
title: {书名}
source: 毅冰·{书名}
type: template
summary: 模板合集：X篇，覆盖Y场景（≤40字）
tags: 3-5个英文小写词，逗号分隔
---
6. 每批结尾输出一行：`【已转录 {M} 篇 / 全书共 {N} 篇，待续】`
7. 只输出 markdown 正文，禁止开场白和总结。

先输出第 1-10 篇。我回复"继续"再输出下一批。
```

## 批次推进话术

- `继续` → 下一批
- `跳到第 X 篇继续` → 断点续传
- `全书共 N 篇，已转录 M 篇，列出遗漏篇目` → 收尾核查
