# P1 · 方法论卡提示词（Notebook ③ 方法论库用）

适用素材：外贸高手客户成交技巧 1/2、十天搞定外贸函电、120个高频业务问题、2024 LinkedIn 274页笔记、客户背调三件套、各类 SOP/流程、展会注意事项、外贸展会口语、两本英语书。

## 使用步骤

1. 一本书 = 一个 source。新开对话，粘贴下方提示词正文，把 `{书名}` 换成实际 source 名
2. 厚书（>200页）防截断两步走：先发「列出《{书名}》的目录结构」→ 再说「按第一部分生成」逐段推进
3. 产出粘贴到 `kb/staging/方法论-{书名}.md`
4. 交叉验证：把蒸馏稿作为**新 source** 传回 notebook，问：「对照原书，这份卡片是否遗漏了关键方法论？有则列出遗漏点」
5. 抽查无误后移入 `kb/01-methodology/`，重跑 `scripts/build_index.py`

## 提示词正文（从这里开始整体复制）

```
你在为一位 AI 外贸顾问整理知识库。请把《{书名}》蒸馏成一份中文方法论卡，严格遵守：

1. 只保留可执行内容：方法步骤、判断标准、策略框架、避坑清单。
   必须删除：课程推广、微信/卖家引流页（出现"hxg3366"字样的页面整页跳过）、扫码页、寒暄、与其他章节重复的案例叙述。
2. 每个要点 = 小标题 + 适用情境 + 具体做法（1-3句）。作者原话里的金句原样保留；英文原文保持英文，不要翻译。
3. 书中出现的邮件/话术模板，这里只保留"句式骨架"并把专名参数化：
   [Name] [Company] [Product] [Country] [Amount]。
   完整模板由另一任务全文处理，此处不展开。
4. 输出结构（严格一致，便于程序建索引）：
---
title: {书名}
source: 毅冰·{书名}
type: methodology
summary: 一句话说明本卡核心价值（≤40字）
tags: 3-5个英文小写词，逗号分隔
---
# {书名}·方法论卡

## 核心观点

（≤5条，每条一句话）

## 方法框架

（按书的知识结构分步骤/分类展开）

## 避坑清单

（每条 = 常见错误 → 正确做法）

## 可复用句式

（如有；没有则省略此节）
5. 目标长度 1500-2500 字。信息密度优先，禁止注水；宁精勿滥。
6. 只输出 markdown 正文，禁止任何开场白、解释或结尾总结。
```
