# P3 · 案例卡提示词（Notebook ② 案例库用）

适用素材：150个毅冰外贸真实案例（解密副本）、50篇外贸业务成单案例、2022-2024 出单手册（6 卷）、7个谈判案例、外贸谈判技巧。

**案例是 agent 的"预演经验库"：不追求全文，追求可复用的决策过程。**

## 使用步骤

1. 一本书 = 一个 source。粘贴提示词正文并替换 `{书名}`
2. **必须分批**：每批 10 个案例；出单手册每卷几百页，按「先列目录 → 每章一批」推进
3. 产出粘贴到 `kb/staging/案例-{书名}.md`
4. 交叉验证：问「列出已覆盖和遗漏的案例编号」
5. 移入 `kb/03-cases/`，重跑 `scripts/build_index.py`

## 提示词正文（从这里开始整体复制）

```
你在为一位 AI 外贸顾问整理案例库。请把《{书名}》中的每个案例压缩成"案例卡"，严格遵守：

1. 卖家推广页（含"hxg3366"、微信引流）整页跳过，不计案例数。
2. 每个案例 ≤8 行，格式：
### 案例{N}：{一句话标题}
- 背景：客户国家/行业/规模 + 核心矛盾点（1行）
- 关键动作：我方做了什么决定性的事（1-2行）
- 关键话术：原话金句 1-2 句（英文原样保留，专名换 [Name]/[Company]/[Product]）
- 结果：成交金额/周期，或失败原因（1行，有数字必须保留数字）
- 可复用套路：这个案例能沉淀什么打法（1句）
3. 失败案例同样保留，"结果"写失败原因——它们对避坑同样有价值。
4. 开头加 frontmatter：
---
title: {书名}
source: 毅冰·{书名}
type: case
summary: 案例合集：X个，行业分布（≤40字）
tags: 3-5个英文小写词，逗号分隔
---
5. 每批结尾输出一行：`【已压缩 {M} 个 / 全书共 {N} 个，待续】`
6. 只输出 markdown 正文，禁止开场白和总结。

先输出第 1-10 个案例。我回复"继续"再输出下一批。
```

## 批次推进话术

- `继续` → 下一批
- `全书共 N 个案例，已压缩 M 个，列出遗漏编号` → 收尾核查
