注册领英第一步： 使用国外 IP 地址访问 www .lin k ed in .com
因为领英根据访问者 ip 地址进行访问重定向， 所以当你访问 ip
是国外 ip 时， 基本能解决这个问题。
一、 怎样保证你的访问 ip 是国外 ip呢？
外贸上网工具请选择： 全局 ( global )模式。
全局的意思是无论访问什么网站， 都使用上网工具国外服务器线
路的 ip 来访问。
通常与之对应的还有智能 PAC 模式， 意思是会根据 pac 文件预
写的规则判断访问哪些网站（ 通常是国内网站） 使用国内本地宽
带接入商分配的 ip ， 访问哪些网站（ 通常是国外网站） 使用国
外服务器线路的 ip 来访问。
通常使用全局模式， 即可顺利访问领英主站， 又回到熟悉的
Linkedin了。
二、 我的外贸上网工具没有分全局模式和智能 PAC 模式， 怎样
能检查我目前是不是国外 ip 在访问呢？
全局模式， 这个名称并不重要， 你只要理解实质是： 使用代理上
网服务的服务器线路 IP 来访问所有网站网页。 即： 哪怕访问国
内网站仍然在用代理上网服务的服务器线路 IP 。
检测方法：
在你能正常访问谷歌的情况下（ 这个是前提， 说明代理浏览服务
生效） ：

在你能正常访问谷歌的情况下， 访问
https : / / www . ip138 . com / 和https : / / whatismyipaddress . co
m / 这两个网站， 测测你的 IP 地址是否已经切换到国外了。
以上这两个网站会自动测出你访问网页的 ip 是本地还是外贸
上网工具线路 ip （ 香港 /新加坡 /日本 /美国 /台湾 / . . . . . .） 。
前一个网站有时候不太准确， 以
https : / / whatismyipaddress . com / 这个网站为准。
如果仍是本地 ip ， 比如某某电信， 某某联通， 则说明你外贸上
网工具默认在使用智能模式。 此时检查你的外贸上网工具设置，
能不能切换到全局模式。
1 ） 如果可以从智能模式切换到全局模式
那么切换之后你可以再次检测： 能正常使用谷歌的情况下访
问ip138 这个网站， 看看 ip 是不是变成非中国大陆的 ip了。
通常切换之后就可以正常访问 Linkedin 主站了。
2 ） 如果不能从智能模式切换到全局模式
则需要手动把领英网址 www . linkedin . com 加到规则文件的
网址里， 强制对这个网址使用代理的 ip 访问。
通常这样处理以后重新开启工具， 这样即可正常访
问Linkedin 主站了。

--- 第3页 ---
一招解决： 在Chrome 浏览器的设置里， 把浏览器首选语言设
置为英文。
修改 chrome 浏览器语言的步骤： 右上角三个点菜单点击 -找到
设置 -左侧高级点开 -语言。 添加英语， 把英语移到顶部（ 也可以
顺便点击把浏览器菜单也用英文显示） 。 记得要关闭 chrome浏
览器再重启浏览器才能生效。
如果还不行就先把默认的两个中文语言删了， 只留英语就可以了。
再不行的话， 可能是工具线路不稳定， 换线路或换工具。
PS ： 并不是把谷歌的搜索界面语言设置为英文， 也不是把已登
录的谷歌账号的语言偏好设置为英文。
这样即可正常访问 Linkedin 主站了。
总结
使用中国大陆外 ip 访问通常即可。
如果还不行， 设置浏览器使用语言为英文然后再次访问即可。
