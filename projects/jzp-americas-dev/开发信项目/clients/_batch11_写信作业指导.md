## 三、正文六段结构（`正文格式规范.md` 权威）

```
① 称呼
② 开场观察（只用一条事实，出自交接单，收在判断句）
③ 我方介绍 + 认证（固定开头 + 只写最相关的一条，带 UL 区间）
④ CTA（一个问句 + 一个低门槛动作）
⑤ 退订承诺句
⑥ Best regards, + {{SENDER_NAME}}
⑦ 图片签名 ← 发送层自动附加，正文里不写
```

### ① 称呼
- **A 档（本批全部是 A 档）** → 直呼其名：`Hi Ron,` / `Hi Shawn,`
- ⚠️ 交接单里姓名不全或职务未确认的 → **不臆造**，只以已知部分相称

### ② 开场观察
- **只用一条**真实事实，**必须出自交接单**
- 收在一个**判断句**上（把事实转成「我懂你的处境」）
- ❌ 不写「贵司是行业领先企业」；❌ 不一次列多家客户名；❌ 不引用员工数/营收

### ③ 我方介绍 + 认证
固定开头（不可改）：
```
We're JZPE Power Transformer, a manufacturer in Suzhou, China.
```
认证（照抄，别记错）：
- **E541627** = 三相液浸**配电**变，UL 45–5,000 kVA / CUL 75–3,000 kVA ✅ 正式 CoC
- **E541626** = 三相液浸**电力**变，750–110,000 kVA ✅ 正式 CoC
- **E544629** = 单相柱上，17 kV ≤500 kVA ⚠️ **仅 ECD 计划函 → 不可称 certified**

🔴 **对美国客户主推 E541627 区间（配电级），不推高压主变** ——
美方**无高压主变成交证据**。加拿大方可谈 E541626。

### ④ CTA
一个问句 + 一个低门槛动作（「回复一个词就行」）。
❌ **首封不报交期**（`X weeks` 一律不出现）；❌ **首封不报价**（price / quote / FOB / USD / discount 不出现）。

### ⑤ 退订承诺句（合规必带，择一）
```
If this isn't useful, reply "stop" and I won't write again.
```
```
Not the right person? Just say so and I'll close the loop.
```
```
If this isn't relevant, just say so and I won't follow up.
```

### ⑥ 结尾（固定两行，就这两行）
```
Best regards,

{{SENDER_NAME}}
```
⚠️ **不写职务、不写邮箱/电话**（由图片签名承担）。

## 四、🔴 红线（违反即返工）

| # | 红线 |
|---|---|
| 1 | **首封不报交期 / 不报价格** |
| 2 | 禁用 `CSA Certified` / `SASO` / `SONCAP`；可写 `built to CSA/IEEE/IEC standards` |
| 3 | 禁用品牌 **`YAWEI`（亚威）** |
| 4 | **对美国客户不谈干变**（我方 UL 只覆盖液浸类）|
| 5 | **E544629（单相柱上）不可称 certified** |
| 6 | 供货记录 PDF **绝不外发**（不作附件/链接/截图）|
| 7 | 必带**退订承诺句** |
| 8 | **一家公司只发 1 人** |
| 9 | spam 词一个都不能出现：`free` / `discount` / `best price` / `limited time` / `click here` / `guarantee` / `100%` / `!!!` |
| 10 | **首封不带附件、不带链接** |

**字数**：首封正文（①–⑥）**60–150 词**。匹配窄的客户允许 60–80 词短版。

## 六、🔴 时区换算表（写「发送时段」时用，**北京时间为准**）

| 客户当地时区 | 当地工作日 09:00–10:00 = 北京（夏令时） | 冬令时（2026-11-01 起） |
|---|---|---|
| **ET** 东部（ON/QC/PA/OH/GA/MD/DE/CT/NY/FL 部分）| **21:00–22:00** | 22:00–23:00 |
| **CT** 中部（MB/TX/IN 部分/TN 部分）| **22:00–23:00** | 23:00–24:00 |
| **MT** 山区（AB/SK/UT/CO）| **23:00–24:00** | 00:00–01:00 |
| **PT** 太平洋（BC/WA）| **00:00–01:00**（次日）| 01:00–02:00 |
| **AT** 大西洋（NL）| **20:00–21:00** | 21:00–22:00 |
| **AZ** 亚利桑那（全年 UTC−7，无夏令时）| **00:00–01:00** | 同左 |

⚠️ **美国 FL 分两区**：Panhandle（Pensacola 一带）为 CT，半岛为 ET。
⚠️ **IN 分两区**：绝大多数县 ET，Lake/Porter 等西北县 CT。
⚠️ **TN 分两区**：东部 ET，中部/西部 CT。
⚠️ **TX 几乎全为 CT**（El Paso 为 MT）。
