# project3 · 外贸开发信生产线

> **输入** = 项目2（找客户）提供的关键人联系信息（邮箱 / 社媒 / 背调）
> **输出** = **开发信 md 存档（`clients/开发信-<客户名>.md`）** + 跟进记录表更新

专注于「**把信息变成一封高质量开发信**」。

## 快速开始

**要写一封开发信：**
1. 读 `00_custom_instructions.md`
2. **过 `00` §四 ①b 发信资格闸门**（不过就不写正文）
3. 读 `01_skill_email_writing.md`（方法论）
4. 按 `05_input_contract_from_project2.md` 拆解交接单
5. **查 `clients/INDEX.md`** 看同类客户用过什么钩子/切片/开场
6. 对照 `02_product_positioning.md` 切产品、`04_do_not_say.md` 过红线
7. 🔴 **先把信写入 `clients/开发信-<客户名>.md`**（全文，3 块正文 + 8 小项批注）
8. **对话只回**：文件路径 + 核心说明 ≤6 条（**不铺正文全文**）
9. 更新跟进表 → 新客户则重跑 `scripts/` 刷新 `clients/INDEX.md`

> 🔴 **交付方式（2026-09-23 起）**：**md 文件是主交付，对话是简报**。
> 不落盘 = 信件不被索引、不能被同类复用 = 白写。详见 `00` §5.1–§5.4。

**要查某个客户的信或跟进信：** 去 `clients/`，或查 `clients/INDEX.md` 索引

## 三层结构（2026-09-23 定型）

本项目由三部分组成，**分工不重叠**：

| 层 | 位置 | 装什么 | 何时读 |
|---|---|---|---|
| **① 写作技能（全局）** | 技能 `foreign-trade-email-dev`<br>`~/.workbuddy-ai/skills/foreign-trade-email-dev/` | 方法论 `01`–`08` + 写作规范<br>`company-profile.md`（我方主体/认证/署名）<br>`素材/`（20 份，1.6M）| 任何写邮件的会话，**自动加载** |
| **② 项目知识库** | `project3/`（**本项目权威版**）| `00`–`05` 六份 md + `clients/` | 进本项目必读 |
| **③ 工作区数据** | 工作区根目录 | 跟进表 / 可发邮箱清单 / 发送时间表 / 邮箱验证报告 | 按需查，**每次更新** |

### 🔴 冲突时以哪层为准

**以 ② `project3/` 为准。**
技能 `foreign-trade-email-dev` 是全局版（别的项目也要用），
`project3/` 是本项目权威版（含本项目特有规则与最新踩坑）。
**两者冲突 → 改 `project3/`，并回头同步技能。**

### 一次写信里三层怎么配合

```
收到交接单
  ↓ ② 读 05 拆字段、读 01 选骨架 + 选钩子
  ↓ ① 技能提供骨架句式与写作规范（Step 3 填参数）
  ↓ ① company-profile.md 提供主体/产品/认证/签名（禁编造的唯一依据）
  ↓ ② 读 02 切产品、读 04 过红线
  ↓ ③ 查可发邮箱清单（退信）+ 发送时间对照表（时区）
  ↓ 输出：Subject×3 / 正文 / 中文批注
  ↓ ③ 更新跟进表（xlsx + md 双份）
```

## 四条铁律

1. **不编造** —— 认证、数字、客户名、电压等级、成立年份
2. **钩子落点只落在自己真有的产品上** —— 接不住的钩子就是自曝
3. **认证红线** —— 无 CSA/SASO/SONCAP；对美不推干变；500kV 不挂 UL 名下；禁用 YAWEI
4. **跟进信必带「无法触达邮箱」提醒段**
