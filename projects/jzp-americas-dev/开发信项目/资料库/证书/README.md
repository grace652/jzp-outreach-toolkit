## 四、绝不能说 / 正确说法

| ❌ 绝不能写 | ✅ 正确写法 |
|---|---|
| `CSA Certified` | `built to CSA/IEEE standards`，或陈述事实：加拿大证书依 CSA C88 / 覆盖 75–3,000 kVA |
| `SASO Certified` / `SONCAP Certified` | 未持有，不提 |
| 干式变有 UL | 对美客户不谈干变 |
| 单相柱上变 / 变电站小主变「已认证」 | 二者**只有 ECD Letter（项目计划函）**，**不是证书** → 只能说 `the project is underway` |

> ⚠️ **ECD Letter ≠ 证书。绝不出示 ECD Letter 充作证书。**
