
## 二、逐段写法

### ① 称呼

**A 档（具名已验证邮箱）** —— 直呼其名：

```
Hi Aaron,
```
```
Hi Mara,
```
```
Hi Ted,
```

**B 档（角色邮箱 `info@` / `sales@`）** —— **必须点名转交**：

```
To the Codale team — could you forward this to Paul Ellis or Drayson
Cervinski?
```
```
To the Gresco team — could you pass this to Steve Gramling or Joey
Arroyo?
```

> 规则：点名的人**必须来自交接单**，不得编造。点名 1–2 人，不要点一串。

---

### ② 开场观察

**用对方的一条真实事实开场**，证明"不是群发"。

写法要求：
- **只用一条**（红线：不堆客户名单）
- **必须出自交接单**（① 级「可直接写」）
- 结尾收在一个**判断句**上，把事实转成"我懂你的处境"

✅ 范例：

```
Fifty years, eighteen branches across four states, and a new automated
distribution centre in Las Vegas. Expansion like that usually shows up
first as gaps on the transformer shelf.
```

```
A local high-voltage contractor with linemen and journeymen on staff —
that usually means the transformer decision sits close to the crew, not
in a procurement department.
```

```
Forty-plus years on the electrical side, and a project list that runs
from the state Supreme Court to six state hospitals — that reads like a
maintenance and change-out pipeline rather than a one-off bid list.
```

❌ 反面：
- 「贵司是行业领先企业」——套话，等于群发
- 一次列三家客户名——像在罗列监视所得
- 引用员工数/营收（第三方估算）——红线

---

### ③ 我方介绍 + 认证

**固定开头**（不可改）：

```
We're JZPE Power Transformer, a manufacturer in Suzhou, China.
```

**产品切片 + 认证**——只写**与对方最相关的一条**，且**必须带 UL 区间**：

```
Our three-phase liquid-immersed line is UL listed — E541627 for
distribution and pad-mount, 45–5,000 kVA; E541626 for power
transformers, 750–110,000 kVA — and built to IEEE C57.12.
```

**认证红线（违反即事故）**：

| ❌ 绝不能写 | ✅ 正确写法 |
|---|---|
| `CSA Certified` | `built to CSA/IEEE/IEC standards` |
| `SASO Certified` / `SONCAP Certified` | 不提 |
| 干式变有 UL | **对美客户完全不谈干变** |
| 单相柱上变 / 小主变 "UL certified" | 只有 ECD 计划函 → `the project is underway` |
| 把 500kV 挂在 UL 名下 | **UL 区间与公司能力分开表述** |

---

### ④ CTA

**一个问句 + 一个低门槛动作**。问句用来拿到对方的需求信息，动作要"一个字就能回"。

```
Which kVA ranges are hardest for you to cover, and would a second source
help? I'll send spec sheets, UL certificates and factory test reports for
whatever you're short on.
```

```
For small pad-mount or station units, what kVA and kV do you normally
specify? I'll send the matching spec sheets and test reports so you have
them on hand for the next change-out.
```

```
Would it help to have our UL certificates, standard spec sheets and
factory test reports on file for your next substation upgrade? Tell me
the kVA range you specify most often and I'll send the matching sheets.
```

**红线**：
- ❌ **首封不报交期**（`X weeks` 一律不出现）
- ❌ **首封不报价**（price / quote / FOB / USD / discount 一律不出现）
- ❌ 不给多个选项让对方做功课（"您可以选 A 或 B 或 C"）

---

### ⑤ 退订承诺句

**合规必带**（美国 CAN-SPAM / 加拿大 CASL 强制要求）。
**一句自然语**，融入正文结尾，**不额外增加词数**。

✅ 三种可用写法（择一）：

```
If this isn't useful, reply "stop" and I won't write again.
```
```
Not the right person? Just say so and I'll close the loop.
```
```
If this isn't relevant, just say so and I won't follow up.
```

❌ **禁止**（群发式模板标志，会触发垃圾过滤）：

```
Click here to unsubscribe
Unsubscribe | Manage preferences
To opt out, visit http://...
```

> ⚠️ 注意：`unsubscribe` 这个词本身**不在 spam 词表里**（2026-09-23 已更正）。
> 禁的是**群发式的**模板句，不是退订这个行为本身。

---

**固定两行，就这两行**：

```
Best regards,

{{SENDER_NAME}}
```

> ⚠️ **不写职务，不写邮箱/电话**（这两类由第 ⑦ 段的图片签名承担）。

## 三、字数

| 项 | 要求 |
|---|---|
| **首封正文（①–⑥）** | **60–150 词**（不含签名） |
| 跟进信 | ≤120 词 |

> 下限 60 不是凑数：60 词以下通常意味着"没讲清买家价值"。
> 但**匹配窄的客户**允许 60–80 词的短版 —— 宁短勿糊。

---

## 四、语气

- **专业克制**：不谄媚（"Great question!"式），不压迫（"限时/最后机会"）
- **按对方规模调整口吻**：微企业不用"行业领先/大集团"话术
- **给台阶**：不逼单

**spam 触发词表（一个都不能出现）**：

```
free ｜ discount ｜ best price ｜ limited time ｜ click here
guarantee ｜ 100% ｜ 全大写标题 ｜ !!!
```
