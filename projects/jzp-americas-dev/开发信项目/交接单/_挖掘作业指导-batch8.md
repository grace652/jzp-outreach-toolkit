## 三、每家必做的四步（顺序不能反）

### 第 0 步 · ⓪ 层反身排除（🔴 最先做，一票否决）

**进官网读「业务描述原句」**，确认**不是**：
- 变压器/开关柜**制造商**（`we manufacture` / `our factory` / `OEM` 自称）
- **竞品代理**（尤其 **YAWEI 亚威** —— 已知禁用品牌）
- **「中国货源 → 北美」通道**（`factory-direct` / `partner factory` / `Asian manufacturing` / 驻华采购）

**判据**：
| 🚨 危险信号 | ✅ 安全信号 |
|---|---|
| `manufacturer` / `we manufacture` / `our factory` | `distributor` / `supplier` / `stock` / `inventory` |
| `exclusive distributor of <对手品牌>` | `authorized distributor of <无竞争关系品牌>` |
| 产品线与我们**高度重合**且自称生产 | 产品线**互补**（开关柜/发电机/线路器材）|

**🆕 本批新增「三合一」判据（三条同时出现 ⇒ 排除，成本最低，优先用）**：
1. **产品跨度极大、跨越不相干行业**（如变压器 + HDPE 管材）
2. **自称 distributor / solution provider，却宣称「生产能力」**（产能是上游的）
3. **无自有工厂地址**（只有商务办公地，无厂址/产线/产能数字）

**加分判据（有疑问时用来定案）**：
- **NAICS 335311 / 335313** ⇒ 制造商 ⇒ 排除（查 `supplychain.wemakeithere.org`）
- **UL 证书「Issued to」** 为**中国工厂** ⇒ 「中国源→北美」通道 ⇒ 排除

> ⚠️ 名字含 `Manufacturing` **不等于**制造商 —— 可能是「服务于制造业」（读全文判断）。
> ⚠️ 「当前是否有**在运**制造能力」才是判据，不看历史。
> ⚠️ **「重绕 / 翻新 / remanufactured」**：只做维修翻新**可留**；**在营绕线/总装产线 ⇒ 排除**。

**不过 → 不写交接单，改写成 `⛔排除{买家号}_{公司}_排除记录.md`**（含证据原文 + URL）。

### 第 1 步 · L-1 锁具名决策人

**优先级顺序**（按可靠性）：
1. **官网 Team / Leadership / Our Team 页** ← 🔴 第一方，最可靠
   （试 `/team/`、`/our-team/`、`/leadership/`、`/about-us/team/`、`/meet-our-team/`、`/company/`）
2. **官网 Contact 页 / 新闻稿署名 / PDF 手册署名**
3. **行业协会会员名录**（加拿大：CMEQ / ECAA / ECABC / NLCA / ECANS；美国：NECA 分会 / AGC / ABC / NETA / EASA）
   → 检索式：`WebSearch "<公司名> <省/州> association member directory contact"`
4. **LinkedIn 个人页** —— ⚠️ **直接抓必然 999/451 失败，必须走 `WebSearch` 取摘要**
5. B2B 库（仅作旁证，**两库互证不算印证**）

**选谁**（每家只选 1 人）：
采购/供应商对接岗 > 国际销售/外贸岗 > 品类经理 > 老板/Owner > 普通业务顾问（兜底）

> 🔴 **一家公司只发 1 人。** 同域名多人 = 排重对象，不是机会。

**通关标准**：拿到 ≥1 份「**姓名 + 职能 + 在职证据 + 个人页 URL**」

### 第 2 步 · 找邮箱（先锁人，再找邮箱）

> 🔴 **batch7 最重要的方法结论（已验证）：小微/家族企业的官网通常只挂 `info@`。
> 想要 A 档，必须离开官网。**

**A 档（具名邮箱）高产来源 —— 按命中率排序，优先试**：
1. 🥇 **州 / 联邦采购与供应商登记库** —— 州 DOT 登记库（如 AZDOT UTRACS）、TX SmartBuy、SAM.gov、州政府采购门户
2. 🥈 **州公司注册年报 / 企业备案文件** —— 州 SoS / 州 Corporation Commission / PUC 备案（含**注册人 ≈ 创始人/老板**）
3. 🥉 **州级项目 / 能效计划 / 补贴名录**（Trade Ally / Approved Contractor 名录，常带 mailto 明文）
4. **母集团官网 Team 页**（⚠️ 邮箱域可能是**母公司**的）
5. **加拿大**：`opengovca.com` 联邦/省注册库、省 SoS、ESA 执照库、行业协会名录

**❌ 明确无效（别浪费时间）**：B2B 库（ContactOut / Prospeo / LeadIQ / RocketReach）、
小微官网 Team 页、LinkedIn 个人页、archive.org

**邮箱链 L0→L7**：
- **L0** 官网全量（Contact / Team / 页脚 / PDF / `data-cfemail` 解码）
- **L1** 政府一手源（见上）
- **L2** 命名规则 + DNS（⚠️ **要有样本才可推演**）
- **L3** B2B 库交叉（仅旁证）
- **L4** 社媒与协会
- **L5** 黄页同址
- **L6** 电话/表单兜底

**🔴 邮箱域 ≠ 官网域（高频陷阱）**：
拿到邮箱后**先 `dig @8.8.8.8 <邮箱域> MX +short`**，确认该域真实存在且收信。
**绝不能按网站域名拼写收件地址。**

**邮箱分档**：
| 档 | 类型 | 可否主送 |
|---|---|---|
| **A** | 具名决策人邮箱（已验证，一手源）| ✅ 主送 |
| **B** | 角色邮箱（`info@` / `sales@`）| ⚠️ **仅点名转交** |
| **B−** | catch-all 域具名邮箱（无法验证）| ⚠️ 暂缓 |
| **C** | 免费邮箱 / 弱域 | 🔴 需电话确认 |

> 🔴 **H6**：仅拿到角色邮箱时，必须跑「升级三步」（挖职能邮箱 → 从回信反推命名规则 → 试推演），
> 失败则**显式写明「仅取得角色邮箱，未取得决策人直邮」并列为风险**。**禁止蒙混过关。**
> ⚠️ **推演出来的邮箱一律算 B 档，不得作主送。**

### 第 3 步 · still_here 在职核验（强制）

| 检查项 | 判定 |
|---|---|
| 个人页 current 公司 = 目标公司？ | ≠ → **离职风险 🔴，邮箱作废** |
| 任职时长 < 30 天 | **新入职** → 改走「恭喜/欢迎」角度 |
| 最近活跃 | 有近期活跃 = ✅ 正面证据 |
| 多人/多源同期提及 | 加强可信度 |

**写入四栏**：`在职称谓 / 任职时长 / 最近活跃 / 离职风险`

> ⚠️ **协会名录给的联系人也必须核**（名录可能收录多年前数据）。

## 五、🔴 红线（违反即返工）

| # | 红线 |
|---|---|
| **H1** | 找不到必须写「未找到」，**禁止**用推测/常识填充 |
| **H2** | 🔴 **绝不编造邮箱/联系方式**（最高优先级）|
| **H3** | 邮箱须格式校验 + ≥1 来源交叉；单一来源须标注「未经第二方印证」 |
| **H4** | 必须标验证状态：`已验证 / 待验证 / 未找到` |
| **H5** | 交叉印证须含 ≥1 **一手源**（**两个 B2B 库互证不算**）|
| **H6** | 仅角色邮箱不得直接交付，须跑升级三步或显式标风险 |
| **H7** | 🔴 **产出必须落盘成 `.md` 文件** |

**其他必守**：
- ❌ 不写交期数字、不写价格词（首封红线，交接单里也别写进「开发信建议」）
- ❌ 不写 `CSA Certified` / `SASO` / `SONCAP` / `YAWEI`（可写 `built to CSA/IEEE/IEC standards`）
- ❌ 对**美国**客户**不谈干变**
- ❌ 供货记录 PDF **绝不外发**
- ⚠️ 遇到 Cloudflare / 验证码 → **停下报告，不硬闯**

**环境坑（务必记住）**：
- 🔴 **本机 DNS 有 fake-ip 劫持**（返回 `198.18.0.x`）→ 验域名**必须** `dig @8.8.8.8` + `curl -sI` 交叉
- 🔴 **LinkedIn 个人页直接抓必失败** → 走 `WebSearch`
- 🔴 `web.archive.org` curl 超时 → 改用 WebFetch
- ⚠️ 目录聚合站会产出**稻草人数据**（555 电话 / 人名机械拼接）→ **整页作废**
- ⚠️ **MX 走 Mimecast（`*.mimecast.com`）→ 直接预判不可探测，且降备选**（项目有 PBL 拦截史）
- ⚠️ 本机 25 端口 SMTP 探测**对 Google / M365 域无效**（RCPT 不回真值）→ **别把探测失败当成地址不存在**
