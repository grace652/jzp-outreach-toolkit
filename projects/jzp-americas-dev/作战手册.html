0执行摘要：三条结论

如果这份手册只读一页，就读这一页。

结论一 · 美国：产品线必须切割，不能整包推

2026-08-26 签署的行政令（编号 14420 / 14421，见附录 B）禁止「外国实体」设计、制造或供应的大电力系统设备被采购、进口或安装，覆盖变电站变压器、高压断路器、电压调节器、仪用互感器等，但明确不适用于仅接入本地低压配电的设施。

→ 我方液浸式配电变压器与美式箱变落在豁免区，美国仍可正常销售；接入 69kV 及以上电网的变电站变压器在美国应视为不可销售，该产品线的北美重心须整体转向加拿大与南美。DOE 细则预计 2026-12-24 前出台，存在追溯风险，须持续盯。

结论二 · 加拿大是当前性价比最高的市场，且是进入北美的成本最低通道

加拿大 8504 全系 MFN 零关税，2025 年钢铝附加税令（SOR/2025-154）不覆盖 8504 章，2026 年 1 月加中协议亦未涉及变压器。与此同时加拿大配电变压器交期已达 100 周以上，BC Hydro / Hydro One / Hydro-Québec 的百亿级资本计划正在释放需求，而 CSA C227.4 与 cUL 资质我方已有。这是全手册里「门槛最低 × 需求最旺」的组合。

结论三 · 南美按频率分梯队，不是按市场规模排序

巴西、墨西哥、秘鲁、哥伦比亚、厄瓜多尔是 60Hz 美标体系，我方 UL / cUL / CSA / IEEE C57.12 产品线可直接适配，无需重新设计；智利、阿根廷是 50Hz 欧标体系，同容量铁芯截面需加大，属可控但真实的重设计成本。因此南美第一梯队是 墨西哥 → 巴西 → 秘鲁/哥伦比亚，智利与阿根廷放第二轮。不要用同一套图纸同时投 60Hz 与 50Hz 市场。

0.2 一句话战略

以「交期」为矛，以「三证齐备」为盾，用加拿大做现金流，用南美 60Hz 国家做增量

为什么墨西哥排第一而不是巴西

巴西单一市场更大，但墨西哥有三重优势叠加：① 产品零改造（60Hz 美标，与 UL/cUL/CSA 体系同源）；② 需求引擎明确——CFE 2025–2030 年 82 亿美元电网投资计划，含 275 条线路、524 座变电站、2300 座变电站数字化；③ 中资已有先例——威胜控股 2025 年与 CFE 签下 5.52 亿元人民币供货协议并在瓜纳华托州建厂，说明 CFE 对中国供应商的接受度已被打开。

代价同样明确：2026 年新关税 5%–35%、NOM 强制认证、以及 CFE 2030 年 60% 本地化目标——长期必须本地化或深度绑定本地伙伴。

南美两个必须落地前解决的不确定项
  1. 巴西 INMETRO 对液浸式配电变压器究竟是强制还是自愿？INMETRO 官网对该品类挂的是自愿性认证规程（RTAC002837），而多篇中文行业文章称 ≤300kVA 属强制。这一条决定巴西是「6–12 个月门票」还是「可以先卖货」，必须向巴西 OCP（认证机构）书面确认，不能靠猜。
  2. 巴西 2026 年加税是否覆盖我方型号？GECEX 第 852/2026 号决议对 1252 项产品加税（0% 升至 7.2%，部分升至 12.6% 或 20%），2026-02-06 与 03-01 分批生效，同时给 105 项产品临时零关税豁免。NCM 查询页显示 8504.21 存在例外清单 20% 税率，与标准 TEC 12.6% 冲突。必须按具体 NCM 逐一核对。

报价纪律：报落地成本，不报 FOB

在约 50% 的综合税负下，继续用 FOB 报价会让客户在清关环节产生巨大的预期落差，直接损害信任。建议报价结构改为：

  • 必报：FOB 价 + 关税估算（注明按当期税则）+ 海运 + 内陆运输 + 保险 = DDP 参考价
  • 必注：「关税按 <日期> 生效税则估算，实际以清关时税则为准」
  • 可选：提供「客户自行清关」与「我方 DDP」两个版本，让客户比较——很多北美客户有自己的报关行和税则意见，让他们自己核反而更快建立信任

7.3 报价策略：关税透明化报价法

  1. 首轮报价必含落地成本拆解——FOB + 关税估算 + 海运 + 内陆 + 保险。在约 50% 税负下，只报 FOB 会让客户在清关时产生巨大预期落差，直接毁掉信任。
  2. 明确标注税则时点——「关税按 2026-XX-XX 生效税则估算，实际以清关时税则为准」。这句话既免责，也显示专业。
  3. 提供双版本——「客户自行清关」与「我方 DDP」。很多北美客户有自己的报关行与税则意见，让他们自己核反而更快建立信任。
  4. 把 2027-12-31 当筹码——对 >10,000kVA 液浸变（8504.23），15% 档位 2027 年底到期，2028 年起回到 25%。推动客户在 2027 年内完成清关，是真实可量化的价值主张，不是话术。
  5. 南美单独定报价逻辑——墨西哥关税 5%–35%、巴西 12.6%（可申请 Ex-Tarifário 至 0%）、哥伦比亚 10% + IVA 19%。Ex-Tarifário 若能覆盖我方型号，II 从 12.6% 降至 0%，这是直接的报价武器，应主动替客户申请。

7.4 品牌授权：用北美业绩做南美背书

必须取得书面授权

南美买家对「你有没有在北美卖过」高度敏感，你现有的成交记录（AC Tesla、Wilson High Voltage、Black & McDonald、Domino Highvoltage 等）是可以合法引用的北美业绩。但引用客户名称与项目细节属于对外披露，必须先取得该客户的书面同意。

建议做法：起草一份简短的中英双语《Reference Authorization》邮件模板，向已成交客户请求「在投标与技术文件中作为案例引用」的授权，并明确可披露的范围（是否可提客户名、是否可提容量与型号、是否可提供联系人作为 reference call）。未取得授权的，一律以脱敏方式表述（如「北美某省级配电运营商，1000kVA 变电站变压器」）。

7.5 复购的真正决定因素：售后与备件前置

调研中最一致的一条结论是：拉美客户的复购取决于「漏油了能不能 72 小时内有人上门」，这比价格更决定能否摆脱低价竞争。

  • 代理条件——公开资料未查到可靠的佣金区间与独家条款数据（不编造）。可确定的行业逻辑：先给非独家 + 首单业绩对赌换独家；合同中必须明确认证成本与关税成本的承担方（巴西 INMETRO 年维护费是常被漏算的隐性成本，占初认证的 20%–40%）。
  • 备件前置仓——建议优先考虑圣保罗或墨西哥城，前置高频备件（套管、密封件、分接开关）。这是从「一单一议」走向「稳定复购」的分界线。
  • 本地维修协作——不一定要自建服务团队，可以先与当地电气服务商签协作协议，把「72 小时响应」变成可承诺的服务条款。
