## 三条核心结论（先看这个）

### 结论一 · 美国：产品线必须切割，不能整包推

2026-08-26 签署的大电力系统行政令（编号 14420 / 14421，**待核实**）禁止外国实体供应的大电力系统设备被采购、进口或安装，覆盖**变电站变压器**，但**明确不适用于仅接入本地低压配电的设施**。

- 液浸式配电变压器 / 美式箱变 → **美国仍可正常销售** ✅
- 接入 ≥69kV 电网的变电站变压器 → **美国应视为不可销售** ❌

> ✅ **2026-09-28 数据侧印证**：成交记录复核发现，**美方外部客户已无高压主变成交**
> （唯一的高压主变记录属我方在美代理 POWER ELECTRONICS）。
> → 政策判断与实际成交**方向一致**：**对美主推配电级**。

### 结论二 · 加拿大是当前性价比最高的市场

8504 全系 **MFN 零关税**，钢铝附加税令不覆盖 8504 章，加中 2026 年 1 月协议未涉及变压器。同时加拿大配电变压器交期已达 **100 周以上**，而 CSA C227.4 与 cUL 资质**我方已有**。门槛最低 × 需求最旺。

> ✅ **2026-09-28 数据侧印证**：外部客户中**加拿大占 62%**（10 : 4），
> 且**峰 2（≥5000kVA 变电站级）5 家全部在加拿大**
> → 加拿大不仅能卖配电级，**高压级也有真实成交**。

### 结论三 · 南美按频率分梯队，不是按市场规模排序

巴西、墨西哥、秘鲁、哥伦比亚、厄瓜多尔是 **60Hz 美标体系**，与 UL/cUL/CSA + IEEE C57.12 产品线**零改造适配**；智利、阿根廷是 50Hz，需重算铁芯截面。

> ⚠️ **2026-09-28 状态：南美方向已暂缓**。
> 早期那批 76 家南美机构与 50 家名单**已由用户撤销**（南美成交记录为 **0**，方向未被验证）。
> 现行策略：**先在被验证的市场（加拿大 + 美国）复制成功**。
> 南美相关材料（补丁、弹药库）**保留备用，但暂不推进**。

**第一梯队：墨西哥 → 巴西 → 秘鲁 / 哥伦比亚**

## 五件必须记住的事

1. **未取得报关行书面税则意见前，不要向客户报承诺性价格。** 手册第 2 章的税率是估算值。
2. **巴西 INMETRO 对液浸式配电变压器是强制还是自愿，官网与行业资料互相矛盾。** 这一条决定巴西是「6–12 个月门票」还是「可以先卖货」，必须向 OCP 书面确认。
3. **墨西哥 NOM 是否承认 UL/cUL/CSA 标记未证实。** 直接决定墨西哥认证成本量级。
4. **南美招标平台全部没有官方英文界面。** 西语/葡语关键词监控是隐性人力成本，要计入预算。
5. **不要把加拿大当美国市场的一部分。** 魁北克有法语要求，省级公用事业资格审查是独立流程。
